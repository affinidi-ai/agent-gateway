# Diagrams

Illustrations used across the repository documentation. They are taken from the Agent
Gateway pages of the [hosted documentation](https://docs.affinidi.com/products/affinidi-trust-fabric/agent-gateway/)
so that the same pictures explain the product in both places.

All are rendered from diagrams the hosted site draws in SVG, HTML, and CSS, in its dark
theme, captured at twice their display size. `runtime-architecture.png` is the diagram on
the hosted overview page.

Each was checked against the source before being adopted. When a hosted diagram changes,
re-check it against the code before replacing the copy here.
